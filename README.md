# Mira_Eric_wedding

Our Story Adventure — Interactive Wedding Invitation Game (HTML5)

## 🎮 Overview
An interactive 8-bit / pixel art web adventure celebrating Mira & Eric's story across Taiwan, Germany, Korea, and beyond.

## 📂 Project Structure
- `index.html` — Main HTML5 web application and game
- `assets/` — Project media assets:
  - `backgrounds/` — Country and scenario background art
  - `collectibles/` — Country-specific items & tokens
  - `players/` — Player sprites and animations
  - `ui/` — Flags, rings, letters, and interface icons
  - `music/` — Background audio (`bgm.mp3`)
- `CUSTOMIZE_GUIDE.md` — Guide for customizing dialogue text, sprites, audio, and levels
- `source_images/` — Original artwork and reference images

## 🚀 How to Run Locally
Start a simple local HTTP server:

```bash
python3 -m http.server 8000
```

Then navigate to [http://localhost:8000](http://localhost:8000) in your browser.
